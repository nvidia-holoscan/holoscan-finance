Calculation, data quality and timing details

Returns use quote midpoints at fixed event-time intervals. Both endpoints must be fresh. Invalid, crossed, wide, zero-size or explicitly halted quotes invalidate the mark. Only instruments with valid returns throughout the current window and nonzero variance enter the matrix. Trades are displayed separately. Observed volatility is a historical estimate, not implied volatility or a forecast.

Covariance uses the sample denominator n−1. Annualization assumes 252 trading days × 6.5 hours. This replay uses the supplied quote fields and does not independently reconstruct or validate NBBO. Intraday sampling remains exposed to microstructure effects; freshness and window length affect the estimates. The first estimate needs the minimum number of completed return bars; seek, loop and restart rebuild that history.

Each comparison repeats the same incremental calculation on the CPU (NumPy and SciPy BLAS) as on the GPU (CUDA kernels), with the same work on both sides: each copies in only the window's new bars and computes its own variance. Ingestion continues while dedicated CPU and GPU workers compute. One comparison is in flight at a time, so the comparison cadence can be CPU-limited. GPU timing includes any host-to-device inputs and compact device-to-host outputs; full matrix transfer, JSON, browser rendering and process startup and process-to-process transfer are outside that timer. Arrival-to-result includes waiting and computation. The entries carry market time, so sender-to-receiver latency is unavailable. Arrival-to-result uses the receiver clock. The speedup is the median CPU time over the median GPU time of the last 120 comparisons that agree and did the same incremental work; rebuilds and startup samples are excluded.

Sequence gaps count the SBE entries missing between the packets the receiver got from one sender, from that sender's first packet. Bar input gaps count what the quote bars did not get, from each generation's first sequence: the sequence gaps, the ring drops, and anything a sender sent before the receiver was ready (the receiver's /healthz answers 200 once it receives).



Equity trade/quote replay with live computation. Quotes and trades are encoded with FIX Simple Binary Encoding 1.0 (one message per UDP datagram, a repeating group of fixed entries) under the replay's own schema: a replay encoding, not an exchange feed.
